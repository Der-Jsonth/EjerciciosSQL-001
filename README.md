Cine Vulkan — Taller Práctico de SQL

Ejercicio práctico desarrollado para la asignatura Base de Datos Aplicada, orientado a reforzar los fundamentos del lenguaje SQL mediante la implementación de una base de datos para la gestión de un cine ficticio.

La actividad consiste en crear y relacionar tres tablas (PELICULA, SALA y FUNCION), aplicar claves primarias y foráneas, modificar estructuras, insertar registros y realizar consultas.

Se trabajan las sentencias CREATE TABLE, ALTER TABLE, INSERT INTO, SELECT y DROP TABLE, además de los conceptos de integridad referencial y relaciones uno a muchos (1).

Herramientas: Oracle FreeSQL / SQL Developer.
Duración estimada: 80 minutos.
Nivel: Introductorio.
